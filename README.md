## Мета роботи

Метою практичної роботи є закріплення навичок роботи з основними елементами керування Windows Forms:

* використання регулятора чисел `NumericUpDown`;
* використання перемикачів `RadioButton`;
* використання прапорців `CheckBox`;
* використання кнопок `Button`;
* обробка подій елементів керування;
* виведення результатів у текстове поле.

## Завдання 1. Модифікована форма реєстрації

У першому проєкті було модифіковано форму реєстрації з практичного заняття №1.

### Реалізовано

На форму додано такі поля:

* ім’я;
* прізвище;
* email;
* рік народження;
* місяць народження;
* день народження;
* стать.

Для вибору дати народження використано елементи `NumericUpDown`:

* рік — від 1900 до поточного року;
* місяць — від 1 до 12;
* день — від 1 до 31.

Для вибору статі використано `RadioButton`:

* чоловік;
* жінка.

Після натискання кнопки `OK` програма перевіряє введені дані та виводить їх у багаторядкове текстове поле.

### Використані елементи

| Елемент         | Призначення                                             |
| --------------- | ------------------------------------------------------- |
| `TextBox`       | Введення імені, прізвища, email та виведення результату |
| `NumericUpDown` | Вибір року, місяця та дня народження                    |
| `RadioButton`   | Вибір статі                                             |
| `Button`        | Виконання дій OK, Очистити, Вихід                       |
| `GroupBox`      | Групування елементів форми                              |

### Перевірка роботи

Приклад введених даних:

```text
Ім’я: Владислав
Прізвище: Чуруканов
Email: abc@gmail.com
Дата народження: 05.08.1997
Стать: Чоловік
```

Очікуваний результат:

```text
Дані користувача:
Ім’я: Владислав
Прізвище: Чуруканов
Email: abc@gmail.com
Дата народження: 05.08.1997
Вік: 28
Стать: Чоловік
```

## Завдання 2. Розрахунок вартості замовлення через RadioButton

У другому проєкті створено програму для розрахунку вартості замовлення пива.

### Умова

Вхідні дані:

* сорт пива;
* кількість порцій.

Вибір сорту реалізовано через `RadioButton`.

Доступні сорти:

* світле;
* темне.

Якщо кількість порцій більша за 20, надається знижка 15%.

### Ціни

| Сорт пива | Ціна однієї порції |
| --------- | -----------------: |
| Світле    |             45 грн |
| Темне     |             55 грн |

### Формула розрахунку

```text
Сума = кількість порцій × ціна однієї порції
```

Якщо кількість порцій більша за 20:

```text
Знижка = сума × 15 / 100
До сплати = сума - знижка
```

### Приклад роботи

Вхідні дані:

```text
Сорт: Світле
Кількість порцій: 25
Ціна однієї порції: 45 грн
```

Розрахунок:

```text
25 × 45 = 1125 грн
1125 × 15% = 168.75 грн
1125 - 168.75 = 956.25 грн
```

Очікуваний результат:

```text
Сорт: Світле
Кількість порцій: 25
Сума без знижки: 1125.00 грн
Знижка: 168.75 грн
До сплати: 956.25 грн
```

### Використані елементи

| Елемент         | Призначення                  |
| --------------- | ---------------------------- |
| `RadioButton`   | Вибір одного сорту пива      |
| `NumericUpDown` | Вибір кількості порцій       |
| `TextBox`       | Виведення ціни та результату |
| `Button`        | Розрахунок, очищення, вихід  |
| `GroupBox`      | Групування перемикачів       |

## Завдання 3. Розрахунок вартості замовлення через CheckBox

У третьому проєкті попередню програму було модифіковано. Вибір сорту пива реалізовано через `CheckBox`, тому користувач може замовити кілька сортів одночасно.

### Умова

Користувач може обрати:

* світле пиво;
* темне пиво.

Для кожного сорту задається окрема кількість порцій.

Якщо загальна кількість порцій більша за 20, надається знижка 15%.

### Ціни

| Сорт пива | Ціна однієї порції |
| --------- | -----------------: |
| Світле    |             45 грн |
| Темне     |             55 грн |

### Формула розрахунку

```text
Сума світлого = кількість світлого × 45
Сума темного = кількість темного × 55
Загальна сума = сума світлого + сума темного
```

Якщо загальна кількість порцій більша за 20:

```text
Знижка = загальна сума × 15 / 100
До сплати = загальна сума - знижка
```

### Приклад роботи

Вхідні дані:

```text
Світле: 13 порцій
Темне: 13 порцій
```

Розрахунок:

```text
13 × 45 = 585 грн
13 × 55 = 715 грн
585 + 715 = 1300 грн
Загальна кількість порцій: 26
Знижка 15% = 195 грн
До сплати = 1105 грн
```

Очікуваний результат:

```text
Світле: 13 порц. × 45 грн = 585.00 грн
Темне: 13 порц. × 55 грн = 715.00 грн
Усього порцій: 26
Знижка: 195.00 грн
До сплати: 1105.00 грн
```

### Використані елементи

| Елемент         | Призначення                              |
| --------------- | ---------------------------------------- |
| `CheckBox`      | Вибір одного або кількох сортів пива     |
| `NumericUpDown` | Вибір кількості порцій для кожного сорту |
| `TextBox`       | Виведення ціни та результату             |
| `Button`        | Розрахунок, очищення, вихід              |

## Висновок

Під час виконання практичного заняття було створено рішення `PracticeWork3`, яке містить три окремі Windows Forms проєкти.

У першому проєкті було модифіковано форму реєстрації. Для вибору дати народження використано елементи `NumericUpDown`, а для вибору статі — `RadioButton`.

У другому проєкті було реалізовано розрахунок вартості замовлення пива з вибором одного сорту через `RadioButton`. Якщо кількість порцій перевищує 20, програма застосовує знижку 15%.

У третьому проєкті було реалізовано вибір кількох сортів пива одночасно за допомогою `CheckBox`. Для кожного сорту можна вказати окрему кількість порцій. Якщо загальна кількість порцій перевищує 20, також застосовується знижка 15%.

У результаті було закріплено навички роботи з елементами керування `NumericUpDown`, `Button`, `RadioButton`, `CheckBox`, а також навички створення обробників подій у Windows Forms.
